Bokamoso's Attendance Frontend Report

1. Project Overview 
This project is web-based attendance system designed to allow students to mark attendance using QR code and enable lectures to monitor and manage attendance records efficiently.
The system is divided into two parts:
- Student Dashboard 
- Lecturer (Faculty) Dashboard 
The focus of this phase was on frontend development only. Backend functionality such as database integration will be done by the other group. 
2. Objectives 
The main objectives of this project were: 
- To design a clean and user-friendly interface 
- To allow lecturers to view attendance records
- To structure the system in preparation for backend integration
3. File Structure 
The following files were created: 
Student Side: 
- index.html
- software.html
- cybersecurity.html
- specialists.html
Lecturer Side:
- Software 1st Year.html
- Software 2nd Year.html
- Cyber 1st Year.html
- Cyber 2nd Year.html
- Specialists.html

Additional Pages: 
- Report.html
- Session Attendance.html
4. Lecturer Dashboard 
The lecturer dashboard includes: 
Sidebar navigation
Top navigation bar 
Multiple pages for managing attendance 
Features include: 
4.1 Course Navigation 
Lecturers can access: 
Software Development 
Cybersecurity 
Specialists
4.2 Year Based Separation 
Each course is divided into: 
1st Year 
2nd Year 
This ensures proper separation of timetables and attendance records 
5. Attendance Overview 
Each year page displays a table with: 
Student Name
Total classes
Classes Attended 
Classes Missed
Attendance Percentage 
6. Sessions Attendance Page
This page allows lecturers to: 
Select course
Select year 
Select date 
It displays:
A list of students 
Their attendance status(Present/Absent)
7. Report Page
The report page allows lecturers to: 
Select date 
Select course 
Select year 
Enter report title 
Write detailed report 
This will later connect to the database to store reports
